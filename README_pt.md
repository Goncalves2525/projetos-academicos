### 1º Ano
#### [1º Semestre] [Simulação Epidemiológica com Métodos Numéricos](https://github.com/Goncalves2525/epidemiological-simulation)
**Descrição:** Desenvolvimento de um simulador de propagação de doenças infeciosas implementando métodos numéricos (Euler e RK4) para resolver equações diferenciais do modelo epidemiológico.

**Tecnologias:** Java

**Unidades Curriculares Relacionadas:**
- APROG (Algoritmos e Programação)
- ALGAN (Álgebra Linear e Análise Matemática)
- AMATA (Análise Matemática)
- PRCMP (Princípios de Computação)

#### [2º Semestre] [Sistema de Gestão Imobiliária](https://github.com/Goncalves2525/real-estate-management-system)
**Descrição:** Uma aplicação abrangente de gestão imobiliária que permite aos utilizadores registar, pesquisar e gerir propriedades para venda ou arrendamento. O sistema inclui funcionalidades para avaliação de propriedades, gestão de clientes, notificações automatizadas, agendamento de visitas e geração de contratos de venda. A aplicação implementa padrões de design orientados a objetos e armazenamento persistente de dados.

**Tecnologias:** Java, JavaFX, JUnit, Programação Orientada a Objetos, MySQL, UML

**Unidades Curriculares Relacionadas:**
- PPROG (Paradigmas de Programação)
- MDISC (Matemática Discreta)
- MATCP (Matemática Computacional)
- ESOFT (Engenharia de Software)

### 2º Ano
#### [3º Semestre] [Sistema de Gestão de Agricultura Biológica](https://github.com/Goncalves2525/organic-agriculture-management-system)
**Descrição:** Um sistema integrado para gestão de operações agrícolas biológicas que suporta planeamento agrícola, monitorização de culturas, gestão de irrigação e distribuição de produtos. O sistema inclui componentes para aquisição de dados de sensores (temperatura, humidade, condições do solo), monitorização de operações agrícolas, controlo de irrigação e fertirrigação, otimização de rotas para distribuição de produtos e relatórios abrangentes através de um caderno de campo. O projeto enfatiza práticas sustentáveis específicas para métodos de agricultura biológica.

**Tecnologias:** Java, Oracle PL/SQL, C/Assembly (para gestão de sensores), Algoritmos de Grafos, Maven, JUnit, UML

**Unidades Curriculares Relacionadas:**
- ARQCP (Arquitetura de Computadores)
- BDDAD (Bases de Dados)
- ESINF (Estruturas de Informação)
- FSIAP (Física Aplicada)

#### [4º Semestre] [Jobs4U - Sistema de Gestão de Aquisição de Talentos](https://github.com/Goncalves2525/Jobs4U-Talent-Acquisition-Management-System)
**Descrição:** Sistema de gestão integrado para empresas de recrutamento que automatiza e otimiza processos de seleção de candidatos. A plataforma oferece gestão completa do ciclo de recrutamento, desde a publicação de vagas até à seleção final de candidatos, com funcionalidades como verificação automática de requisitos, gestão de entrevistas e análise de qualificações através de processamento de linguagem natural. Desenvolvido como um projeto integrador multidisciplinar, aplicando conceitos de redes, sistemas distribuídos, engenharia de software e processamento de linguagem.

**Tecnologias:** Java, ANTLR4, Maven, Base de Dados H2, TCP/IP, C (processos e threads), JPA, PlantUML, Git, HTML/CSS, GitHub Actions, API REST, JUnit, Linguagens de Domínio Específico (DSL), Processamento de Linguagem Natural (PLN)

**Unidades Curriculares Relacionadas:**
- RCOMP (Redes de Computadores)
- SCOMP (Sistemas de Computadores)
- LPROG (Linguagens de Programação)
- EAPLI (Engenharia de Aplicações)

### 3º Ano
#### [5º Semestre] [Sistema de Gestão de Consultas Cirúrgicas e Recursos](https://github.com/Goncalves2525/Surgical-Appointment-and-Resource-Management-System)
**Descrição:** Um sistema abrangente de gestão de saúde para operações cirúrgicas que integra registos de pacientes, agendamento de operações e gestão de recursos. A plataforma apresenta uma interface web responsiva, visualização 3D de pisos hospitalares, agendamento otimizado de cirurgias através de técnicas de IA e total conformidade com o RGPD. O sistema foi desenvolvido utilizando uma arquitetura descentralizada com múltiplos módulos especializados comunicando através de APIs e WebSockets, fornecendo funcionalidades como gestão de registos médicos de pacientes, planeamento automatizado de consultas e visualização de recursos em tempo real.

**Tecnologias:** Angular, ASP.NET Core, Entity Framework, Express.js, MongoDB, Three.js, Prolog, WebSockets, TypeScript, C#, JavaScript, implementação de conformidade com o RGPD, Arquitetura Limpa

**Unidades Curriculares Relacionadas:**
- SGRAI (Sistemas Gráficos e Interfaces)
- ASIST (Administração de Sistemas)
- ALGAV (Algoritmos Avançados)
- ARQSI (Arquitetura de Sistemas)
